
# Basketball Scoreboard 🏀

An interactive basketball scoreboard built from scratch using HTML, CSS, and JavaScript as part of my web development practice.

## 📖 Project Overview

For this coding challenge, we were provided with a visual design of a basketball scoreboard and tasked with recreating it from scratch.

The goal was to build a scoreboard that closely matched the reference design while making all six scoring buttons functional.

This project provided an opportunity to practice translating a visual design into code and adding interactivity through JavaScript.

## 🎯 Project Requirements

- Recreate the basketball scoreboard using the provided design reference.
- Build the project from scratch.
- Display separate scores for the Home and Away teams.
- Make all six scoring buttons functional.
- Update the appropriate team's score when a button is clicked.

## 🛠️ Technologies Used

- **HTML** — Structure and content
- **CSS** — Layout and visual styling
- **JavaScript** — Scorekeeping functionality and interactivity

## 💡 What I Practiced

- Translating a visual reference into a working webpage
- Structuring and styling a user interface
- Using JavaScript to respond to button clicks
- Updating displayed scores dynamically
- Using Git and GitHub to track and publish project changes

## 📚 Learning Journey

This project is part of my ongoing journey to strengthen my front-end development skills through hands-on coding challenges.

I also used this project to practice version control with GitHub Desktop, including committing changes and pushing updates to GitHub.
